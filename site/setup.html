Инструкция по подключению

Выберите своё устройство. Быстрее всего — прописать DNS-сервер 147.45.114.74. Для шифрования используйте DoH/DoT (адреса ниже).

❗ Если на телефоне всё равно пишет «not supported in your country»
  1. Откройте страницу проверки именно в том браузере, где не открывается Gemini. Если она показывает Россию — браузер не использует EuroDNS. Решение — заставить его использовать наш DNS (п.2–3).
  2. Надёжнее всего — прописать DNS 147.45.114.74 как DNS-сервер в сети Wi-Fi (долгое нажатие на сеть → Изменить → Показано доп. → Параметры IP → Статический → DNS 1 = 147.45.114.74) или на роутере. Тогда его используют все приложения и браузер.
  3. Private DNS (DoT) тоже работает и в Chrome, и в приложениях Google: Настройки → Сеть и Интернет → Частный DNS → smartdns.147-45-114-74.sslip.io. Сервер отдаёт запись SVCB (alpn=h2), поэтому QUIC/HTTP3, ECH и кэш больше не мешают — отключать QUIC и чистить кэш не нужно.
  4. Если провайдер режет порт 853 — включите в Chrome безопасный DNS (DoH): Настройки → Конфиденциальность и безопасность → Безопасность → «Использовать безопасный DNS» → «С другим поставщиком» → https://smartdns.147-45-114-74.sslip.io/dns-query.
  5. iOS: профиль eurodns.mobileconfig (DoH) применяется ко всем приложениям; либо DNS 147.45.114.74 в настройках Wi-Fi.
  6. Редко: если отдельное приложение упрямится — перезапустите его (иногда помогает «Clear host cache» в chrome://net-internals/#dns). Это не обязательно.

🎮 Xbox One / Series X|S

  1. Нажмите кнопку Xbox на геймпаде → Профиль и система → Параметры → Общие → Параметры сети.
  2. Дополнительные параметры → Параметры DNS.
  3. Выберите «Вручную»:
    1. Основной DNS: 147.45.114.74
    2. Дополнительный DNS: 147.45.114.74
  4. Сохраните и перезагрузите консоль. Проверка сети → тест подключения к сервисам Xbox Live.
IPv6. Если у консоли есть IPv6-адрес, либо пропишите наш IPv6 2a0d:6c2:17:51b:: в настройках роутера, либо отключите IPv6 на роутере — иначе часть запросов пойдёт мимо EuroDNS.

🎮 PlayStation 4 / 5

  1. Настройки → Сеть → Настройки подключения → Установить соединение с Интернетом (LAN или Wi-Fi).
  2. Выберите «Настройка вручную» → «Дополнительные настройки».
  3. Раздел Настройки DNS → «Вручную»: IPv-адрес DNS: 147.45.114.74 (второй оставьте или тоже 147.45.114.74).
  4. MTU — «Автоматически», прокси — «Не использовать». Сохраните и проверьте соединение с Интернетом.
Если PS получает IPv6 — отключите IPv6 на роутере или пропишите там 2a0d:6c2:17:51b::.

💻 Windows 11 / 10

Рекомендуемый способ (Windows 11 — DoH):

  1. Параметры → Сеть и Интернет → Wi-Fi/Ethernet → Свойства оборудования.
  2. «Назначение DNS-сервера» → Изменить → «Вручную», включите IPv4.
  3. Предпочтительный: 147.45.114.74.
  4. «Предпочтительное шифрование DNS» → «Только шифрование (DNS через HTTPS)» → введите URL:
https://smartdns.147-45-114-74.sslip.io/dns-query

Стандартный способ (Windows 10 и раньше):

  1. Панель управления → Центр управления сетями → ваше подключение → Свойства.
  2. «IP версии 4 (TCP/IPv4)» → Свойства → «Использовать следующие адреса DNS» → 147.45.114.74. OK.
  3. В консоли: ipconfig /flushdns для сброса кэша.

🍏 macOS (Monterey и новее)

  1. Системные настройки → Wi-Fi (или Сеть) → Подробности у активного подключения → вкладка DNS.
  2. Нажмите «+» и добавьте 147.45.114.74 (и при желании 2a0d:6c2:17:51b::). Удалите прежние серверы или поставьте наши первыми.
  3. OK. Сброс кэша: sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder.

📱 Android 9+

Способ 1 — DNS в Wi-Fi (надёжнее всего, используют все приложения и Chrome):

  1. Удерживайте подключённую сеть Wi-Fi → «Изменить сеть» → «Дополнительно» → Настройки IP: «Статический».
  2. DNS 1: 147.45.114.74 · DNS 2: 2a0d:6c2:17:51b:: (или только IPv4). Сохранить.

Способ 2 — Private DNS (шифрованный DoT) — работает и в Chrome, и в приложениях Google: Настройки → Сеть и Интернет → Дополнительно → Частный DNS → «Имя хоста поставщика»:

smartdns.147-45-114-74.sslip.io
Никаких доп. настроек не нужно. Сервер отдаёт запись HTTPS/SVCB (alpn=h2 + адрес нашего прокси), поэтому Chrome и приложения Google сами идут на EuroDNS по HTTP/2 — протоколы QUIC/HTTP3, ECH и старый кэш больше не мешают. Отключать QUIC, чистить кэш или ставить флаги не требуется.
Если провайдер блокирует порт 853, включите в Chrome безопасный DNS (DoH) → «С другим поставщиком» → https://smartdns.147-45-114-74.sslip.io/dns-query. Для мобильного интернета (не Wi-Fi) используйте именно этот способ 2 — он действует на весь трафик без root.

📱 iPhone / iPad (iOS 14+)

Способ 1 — профиль (автоматически настроит DoH):

  1. Откройте в Safari: /ios/eurodns.mobileconfig
  2. Разрешите загрузку профиля → Настройки → Профиль загружен → Установить.

Способ 2 — вручную (iOS 17+ / DNS-настройки):

  1. Настройки → Wi-Fi → (i) у сети → Настройки DNS → Профиль → Добавить сервер DNS → URL DoH:
https://smartdns.147-45-114-74.sslip.io/dns-query

🏠 Роутер (весь дом одним махом)

В панели роутера раздел WAN / Интернет / LAN → DNS-серверы. Поставьте:

IPv4 DNS: 147.45.114.74

Примеры размещения по вендорам:

  • Keenetic: Интернет → Wi-Fi/PPP-соединение → «Использовать эти DNS-серверы» → 147.45.114.74; в «Система → Сетовые правила» можно включить DNS-over-TLS к smartdns.147-45-114-74.sslip.io.
  • TP-Link / Mercusys: Advanced → DHCP → DNS (или Internet → DNS) → основной/резервный 147.45.114.74.
  • ASUS: WAN → Internet Connect → «These DNS servers» → 147.45.114.74.
  • D-Link: Network Settings → Internet Connection → Manual DNS → 147.45.114.74.
  • MikroTik: IP → DNS → Servers: 147.45.114.74 (+ `DoT-Server=smartdns.147-45-114-74.sslip.io`).
  • OpenWrt: Network → Interfaces → DHCP/DNS → «Use custom DNS» = 147.45.114.74; для DoH — пакет odoh или smartdns.
  • Xiaomi / Huawei / ZTE / Tenda / SNR: «Настройки LAN» или «WAN» → «DNS» вручную → 147.45.114.74.
Отключите IPv6 на роутере (или пропишите там же IPv6 DNS 2a0d:6c2:17:51b::), иначе устройства могут частично резолвиться мимо EuroDNS.

🌐 Только в браузере (DoH)

Chrome / Edge / Opera / Яндекс. Настройки → Конфиденциальность и безопасность → Безопасность → «Использовать безопасный DNS-сервер» → «С другим поставщиком»:

https://smartdns.147-45-114-74.sslip.io/dns-query

Firefox. Настройки → Приватность и защита → «DNS через HTTPS» → «Максимальная защита» → «Выбрать провайдер: По выбору» → тот же URL.

Этот способ влияет только на трафик браузера (другие приложения и игры — нет).

📺 Smart TV (Samsung / LG) и приставки

На ТВ DNS обычно задаётся только при настройке сети вручную (IPv4 → DNS → 147.45.114.74). Если ТВ не даёт задать DNS — настройте DNS на роутере (см. выше) или раздайте Wi-Fi с нужными DNS. На Android TV: Настройки → Сеть → «Частный DNS» → smartdns.147-45-114-74.sslip.io.

Как убедиться, что работает: на этом устройстве откройте страницу /test/ (будет зелёным) или зайдите на gemini.google.com — сообщение «not supported in your country» быть не должно.
