Как настроить устройство

Главное правило: DNS должен быть прописан на самом устройстве / роутере. Установка только в браузере не затрагивает игры и приложения.

Вариант А (надёжный): частный DNS (DoT)

  1. Настройки → Сеть / Подключения → Дополнительно → Частный DNS-сервер.
  2. Имя хоста: smartdns.147-45-114-74.sslip.io → Сохранить.

Вариант Б (если вариант А не работает — Chrome может его игнорировать): в самом Chrome — Настройки → Конфиденциальность → Безопасность → Безопасный DNS → «С другим поставщиком» → вставьте наш DoH:

https://smartdns.147-45-114-74.sslip.io/dns-query

Если сеть блокирует порт 853 (DoT), но не блокирует DoH — вариант Б сработает.

Chrome может использовать свой безопасный DNS и игнорировать системный. Чтобы точно пускать gemini.google.com через EuroDNS, укажите наш DoH прямо в Chrome:

  1. Настройки → Конфиденциальность и безопасность → Безопасность.
  2. «Использовать безопасный DNS-сервер» → вкл → «С другим поставщиком».
  3. Вставьте: https://smartdns.147-45-114-74.sslip.io/dns-query
https://smartdns.147-45-114-74.sslip.io/dns-query

В Safari откройте профиль EuroDNS и установите его (Настройки → Профиль загружен). Или вручную (iOS 17+): Wi-Fi → (i) → Настройки DNS → URL DoH: https://smartdns.147-45-114-74.sslip.io/dns-query.

Панель управления → Центр управления сетями → подключение → Свойства → IP версии 4 (TCP/IPv4) → «Использовать следующие DNS» → 147.45.114.74. Или в Windows 11 укажите DoH-URL https://smartdns.147-45-114-74.sslip.io/dns-query в параметрах сети.

В панели роутера (WAN/LAN → DNS) впишите 147.45.114.74 и отключите IPv6 (или пропишите IPv6 2a0d:6c2:17:51b::). Тогда все устройства дома сразу работают через EuroDNS.
